# Group Money

**Group Money** is a polished, mobile-first static web demo of a South African **shared group money OS** (stokvel / burial society / choir).

Sample group: **Kopano Stokvel · Bloemfontein**. Demo / sample ZAR data on a **single device**. **NOT** a bank. **NOT** an NCR credit provider. **NOT** financial advice.

Shared DNA with [Life Desk](https://esteprinsloo101-web.github.io/life-desk/) and [Farm Desk](https://esteprinsloo101-web.github.io/farm-desk/): the app **reminds, prepares, closes books**; humans **Approve** payouts.

## Live URL

**https://esteprinsloo101-web.github.io/group-money/**

## Modules

| Module | Role |
|--------|------|
| **Today** | Due processes · pot / late KPIs · Gumroad CTA |
| **Members** | Roster · paid / late / pending |
| **Ledger** | Period progress · contribution entries |
| **Cycles** | Payout sheet · Approve · cycle history |
| **Loans / advances** | Log only (not credit) |
| **Disputes** | Open items |
| **Meeting pack** | In-browser export stub |
| **Settings** | Modules · processes · related pack link |

## Process types

- **Record contribution** — member → amount → log
- **Attest paid** — review roll → attest → lock
- **Period close** — totals → late notes → close
- **Payout prep** — sheet → committee Approve → mark prepped
